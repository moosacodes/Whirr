Limitations

    What offline verification proves

    Integrity: these exact bytes were signed by the holder of the embedded installation key, the receipt hashes to the stated value, and each interval is included in the signed Merkle root.

    Sensing: the bundle may carry a signed client claim about the microphone path. It is not physical proof that an object was present, switched on or the only sound source.

    Payment: offline verification cannot contact PayPal. A capture reference is installation-recorded unless separately reconciled online with the provider.

    Key substitution: without an out-of-band key pin, the embedded key is self-attested. Pinning a fingerprint detects a different signer; it does not by itself establish the signer's real-world identity.
