## Product description

Whirr 6.0 is a teachable physical promise engine. An owner demonstrates an ordinary object's idle, running, and background sound. A local event model learns the acoustic vocabulary and refuses uncertain sound. A deterministic compiler turns a narrow English proposal into exact fixed-price terms. A buyer approves the terms and, when configured, a PayPal Sandbox authorization. Whirr evaluates the physical observation against the approved temporal rules and requests a supported capture only when the evidence qualifies. The portable proof separates installation integrity, sensor provenance, inference, contract compliance, provider confirmation, and real-world fulfillment.
